## Project goal
InvestFlow is a small full-stack portfolio project used to practice modern software development and prepare for interviews.

## Working style
- Implement the project step by step, one feature at a time.
- Keep explanations concise by default.
- Prefer clear, maintainable solutions over clever ones.
- Update tests and documentation alongside each feature.

## Planning rules
- Keep plans simple.
- Prefer the repo’s standard tools and commands first.
- When introducing a technology or framework, explain:
  - why the project needs it
  - what a simpler alternative would be
  - the tradeoffs involved

## AI assistance rules
- Explain decisions clearly and briefly.
- Do not go deep unless asked.
- Challenge the solution when there is a better or simpler approach.
- Surface risks, edge cases, and interview-relevant tradeoffs.
- Ask before making major architectural changes.

## Stack
- Frontend: React
- Backend: Kotlin + Spring Boot
- Database: PostgreSQL

## Quality bar
- Favor readable code and straightforward architecture.
- Add or update tests for behavior changes.
- Keep documentation in sync with implementation.

## Interview focus
When relevant, emphasize:
- design choices
- tradeoffs
- alternatives
- scalability limits
- testing strategy
- maintainability
